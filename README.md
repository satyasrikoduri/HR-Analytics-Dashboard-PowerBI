# 📊 HR Analytics Dashboard

## Overview

An interactive **HR Analytics Dashboard** developed using **Power BI** to analyze employee attrition, workforce demographics, employee satisfaction, and retention trends. The dashboard provides actionable insights through dynamic visualizations and KPI tracking to support HR decision-making.

## Project Objectives

- Analyze employee attrition trends
- Monitor workforce demographics
- Track employee satisfaction and work-life balance
- Identify high attrition departments and job roles
- Support HR decision-making with data-driven insights

## Tools & Technologies

- Power BI
- SQL Server
- Microsoft Excel
- DAX
- Power Query

## Dataset

The project uses the **IBM HR Analytics Employee Attrition & Performance** dataset.

### Data Preparation

- Imported raw dataset from Excel
- Cleaned and transformed data using Power Query
- Loaded dataset into SQL Server for analysis
- Connected SQL Server to Power BI
- Created DAX measures and calculated columns for KPIs and visualizations

## Key KPIs

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Monthly Income
- Average Job Satisfaction
- Average Environment Satisfaction
- Average Work-Life Balance
- Average Years at Company
